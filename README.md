# Data Format Converter

Free data format tools that run entirely in your browser: [dataformatconverter.com](https://dataformatconverter.com)

Your data is never uploaded. There are no accounts, cookies, ads or analytics.

## Tools

| Tool | Notes |
|---|---|
| [JSON to CSV](https://dataformatconverter.com/json-to-csv) | Reads JSON and JSON Lines (NDJSON), flattens nested objects, merges different keys into columns |
| [CSV to JSON](https://dataformatconverter.com/csv-to-json) | Detects the delimiter, keeps leading zeros, handles quoted fields |
| [XML to JSON](https://dataformatconverter.com/xml-to-json) | Keeps attributes, turns repeated elements into arrays, reports the line of any error |
| [JSON to XML](https://dataformatconverter.com/json-to-xml) | Choose the root element, write attributes with `@` keys |
| [YAML to JSON](https://dataformatconverter.com/yaml-to-json) | Follows YAML 1.2, expands anchors, combines multiple documents |
| [JSON to YAML](https://dataformatconverter.com/json-to-yaml) | Keeps key order, quotes strings only when needed |
| [CSV to XLSX](https://dataformatconverter.com/csv-to-xlsx) | Keeps leading zeros and long IDs intact |
| [JSON Compare](https://dataformatconverter.com/json-compare) | Ignores key order, matches arrays by ID, outputs a list or an RFC 6902 JSON Patch |

## Check that nothing is uploaded

Every page is served with a Content Security Policy containing `connect-src 'none'`, so the browser blocks the page from opening network connections. You can confirm it yourself:

1. Open your browser's developer tools and switch to the Network tab.
2. Run a conversion and check that no request carries your data.

The policy is set in [`build.mjs`](build.mjs), and all conversion code is in [`src/lib`](src/lib).

## Development

Requires Node.js.

```bash
npm install
npm test
npm run build
npm run serve
```

The preview runs at `http://localhost:8766`. Pages are rendered to `dist/` by `build.mjs`, and the worked examples on each page are generated by the real converters.

The live site runs on Cloudflare. To publish it, build first and then deploy:

```bash
npm run build
npx wrangler deploy
```
